Robust and Explainable Detection of Indirect Prompt Injection in Retrieval-Augmented Generation Systems

A local research prototype that screens retrieved text before it reaches a language model. This case study documents how the system was implemented, what its experiments showed, and where the defense failed.

01 / THE PROBLEM

Retrieved data is not an instruction source.

A RAG application retrieves external documents to answer a user's question. A relevant document can also contain an attacker-written instruction. If the generator treats that text as authoritative, the answer may be redirected away from the user's legitimate task.

The project's goal was to investigate a lightweight, inspectable admission boundary and measure both attempted-attack handling and the cost to legitimate answers. The study was restricted to local execution and authored English-language synthetic examples.

02 / THE IMPLEMENTATION

A modular inspection-and-gating pipeline

Python modules operate locally. TF-IDF retrieval selects candidate passages; the detector provides independent signals; the gate controls what reaches Ollama.

  1. 01RetrieveTF-IDF, cosine similarity, identifiable passages.
  2. 02PreprocessOverlapping windows with original-text offsets.
  3. 03DetectFrozen MiniLM encoder, fitted classifier and structural rules.
  4. 04DecideWeighted fusion, uncertainty and allow/quarantine/block gate.
  5. 05GenerateOnly approved context reaches local Ollama; records remain auditable.

The logical design is broader than some completed capabilities. The current system uses TF-IDF rather than embedding-based retrieval and does not include an autonomous agent, production monitoring or a human review service.

03 / EVALUATION

Repeatable observations, limited security claims

Each run used 12 benign cases and 12 attack-bearing cases, evaluated under undefended, rules-only, semantic-only and hybrid modes. Three repetitions per case and mode yielded 288 timed observations per run, not 288 independent security cases.

Important limitations remain: the detector missed six attacks, one benign case was overblocked, independent and adaptive attack benchmarks were not completed, and production readiness was not established. The semantic inference path lacks an independently enforced hard process deadline.
